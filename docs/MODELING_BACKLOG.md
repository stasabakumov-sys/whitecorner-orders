# Modeling release — 5 October 2026

Following PR #208, the next release implements:

- Shared parts menu: assembly controls are visible only in Select parts; Rotate collapses them without resetting the assembly.
- Shaker recess: only the outward inner plane is 8% darker in linear RGB; the 12 mm recess and frame remain unchanged.
- Closed roof: a 12 mm MDF bottom panel fits inside the existing skirt with four actual post cutouts. Overall roof height remains unchanged.
- Optional glass racks: 70 × 105 × 406 mm reference envelope, centred along depth; outer mounting plates are 120 mm from the left and right edges. Quantity and spacing update with cart length. Bowl diameter uses centre spacing minus 4 mm clearance; stem/base fit requires physical verification. Rod diameter and slot geometry are estimates from the supplied photos.
- Dulux Featherbed: #AECDE5, RGB 174/205/229, from https://www.dulux.com.au/colour/blues/featherbed/.
- Preview fills the available left area; optional Studio, Event and Office backgrounds keep the 3D cart and real shadow interactive. Event and Office use generated photographic scene plates, not navigable 3D rooms.

All controls remain in English. Preview options do not overwrite the stored CAD model.
