# Shop Floor phone pilot and Hub test orders

Open https://stasabakumov-sys.github.io/whitecorner-orders/angular2/?app=shop-floor#/shop-floor on the phone. Sign in with the existing Hub account. On iPhone use Safari → Share → Add to Home Screen; on Android use Chrome → Install app (or the in-app install button when available). The icon launches Shop Floor in a standalone window. No app-store account is required.

Load products and templates online before using timers offline. The shell is cached by Angular service worker 21.2.22; IndexedDB retains the worker's product choices, work data and queued commands. Only operational IDs/names/stages are added to the offline product list. API responses are excluded from service-worker caching. Existing authentication is required; expired sessions, first sign-in, board transitions and corrections require connectivity. Browser storage eviction/private browsing can remove offline data. Sync pending actions before switching devices. Updates are offered through an explicit reload after the queue is synchronized.

The owner requested two practice orders. Migration `20260912000200_hub_test_orders.sql` and `supabase/seeds/shop-floor-test-orders.sql` were applied as one transaction through the owner's Supabase SQL Editor on 2026-09-12. The result was verified: TEST-BACKDROP / TEST Backdrop and TEST-CART / TEST Cart, quantity 1 each, New, source `hub_test`, Wix ID NULL. Parts and expected minutes are intentionally unset for the owner to configure. Seed reruns preserve production progress.

Existing imported orders default to source `wix` and keep their unique required Wix identity. Test source is immutable, cannot acquire a Wix ID, has zero order totals and no contact/delivery address. Database guards reject fulfilment/shipments and suppress financial snapshots for test orders. Test items do not register into the packaging catalogue. The UI excludes them from fulfilment and costing. The internal Pickup value also prevents older delivery-review clients from requesting courier quotes; it does not authorize collection. Production and Shop Floor remain available. No Wix/customer/booking data were changed.
