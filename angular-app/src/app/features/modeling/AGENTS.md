- Use light compact sections with thin borders and rounded corners. Keep controls, labels, values, help, and state text at 10px / weight 400 / line height 1.45 with the inherited Inter font. Section headings are 10px / 600. Verify computed styles in the browser, including nested components, dialogs, loading, and errors; save a review screenshot.
- Order the first sections Dimensions → Finish → Options → Front logo. Parts & assembly and Building stay below. Binary options use checkboxes and section summaries show None or the selected value.
- Finish combines Body, Table top, and Side shelves. Side shelves inherit the table top by default and may have an independent finish. Use the table top swatch pattern. Preserve painted/raw and colour semantics for catalogue variants and pricing.
- Round the free external edges of the entire product at the selected radius, for every part and finish, including the tabletop outer contour. Keep glued/mating faces, panel-to-border joints, side shelf seams and mounting interfaces square. Apply this rule to all current and future models, not only tabletops. The entire plywood edge thickness has plywood edge texture. Before release verify an actual exposed bevel, flush joints and unchanged dimensions with a geometry regression test and a browser screenshot; do not infer rounding from the setting alone.
- Coplanar tabletop and side shelf faces using the same finish must have the same colour and paint properties. Keep flat face normals separate from bevel normals so shelf size cannot change its apparent colour. Independent shelf finishes remain supported.
